# Random-Shuffler
A Java console application that demonstrates the implementation of the efficient Fisher-Yates shuffle algorithm. It randomly shuffles an array of integers in place with O(n) time complexity and compares the shuffled array against the original reference array to calculate how many elements remained in their initial positions.
